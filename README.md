## 📌 Project Overview

This project provides a comprehensive analysis of Blinkit's sales performance, customer demographics, and inventory efficiency. By transforming raw transactional data into actionable insights, this dashboard helps stakeholders identify high-growth opportunities and optimize delivery performance.

## 📊 Key Business Insights & Impact

- 📈 **Revenue Growth:** Identified top-performing customer segments contributing to **65% of total revenue**.
- 🔻 **Retention Analysis:** Pinpointed a **15% drop-off** in weekend order frequency, suggesting a need for weekend-specific promotions.
- ⚙️ **Operational Efficiency:** Automated data cleaning workflows, reducing reporting time by **40%**.
- 🛍️ **Customer Behavior:** Discovered a **12% correlation** between evening time slots and bulk-purchase grocery categories.
